Open data

Every run is published as typed tables (events, messages, channels, turns, laws, scores) plus the raw logs, in the charter-runs dataset under CC BY 4.0. The simulator is open source (MIT); new runs are added with one command.

-- every DM in every run, straight from the Hub (DuckDB)
SELECT run_id, channel_id, sender, text
FROM 'hf://datasets/zachmacsmith/charter-runs/runs/*/*/messages.parquet'
WHERE channel_kind = 'dm'
LIMIT 20;
