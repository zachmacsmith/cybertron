# Standing orders

## Summary

Routine work runs on standing orders the agent sets, until it changes them. Reflexes, fallbacks and policies come later.

## Decided

- D4-16: routine work runs on standing orders the agent sets; reflexes, fallbacks and policies come later.

## Mechanics

- **A routine** is a standing order the agent sets ("each day: forage 2, store what I carry above 2 food"); the engine runs it in
  the units the day's plan leaves unused, in order, until the agent changes it. Setting or changing one costs nothing, and it is
  shown in the agent's prompt every day (D4-16).
- Standing orders are hooks an agent owns on the engine's primitives, binding only itself (38.07 §5).

## Open

- Reflexes, fallbacks and policies (38.06 §4): later (D4-16).
- Being called less than every day (38.06 §5): later.
