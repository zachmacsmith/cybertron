# Life stages

## Summary

Childhoods are short, counted in rounds: a few rounds cared for, a few of menial tasks without a model call, then a youth as an
agent. Prompts name life stages, never ages in years. Runs start with people of every age; there are no time skips. Youth learn
faster and keep it longer.

## Decided

- D4-19: short childhoods counted in rounds: 1-3 rounds cared for, 3-4 rounds of menial tasks (no model call), then a youth as an
  agent; prompts name life stages, never ages in years; no time skips; youth learn faster and keep it longer.

## Mechanics

| Stage | Rounds | Agent |
|---|---|---|
| infant | 1-3, cared for | no |
| child | 3-4, menial tasks | no (no model call) |
| youth | until adulthood | yes; learns faster, and what it learns decays more slowly |
| adult | | yes |
| elder | | yes; fewer units (agents/work.md) |

- Prompts say the stage ("a youth", "an elder"), never an age in years (D4-19).
- A run starts with people of every age and family; there are no time skips (D4-19).
