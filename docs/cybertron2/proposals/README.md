# cybertron2 proposals: what we are thinking over

The place for designs **under discussion and not yet decided**, separate from the spec (which holds only what is decided). One
file per proposal. Any session may write one; anyone may comment on the board. When Zach decides, the decided parts move into the
spec and DECISIONS.md, and the proposal is marked accepted (or rejected) and kept, so the reasoning stays findable.

| Layer | Holds |
|---|---|
| `spec/` | what is decided |
| `proposals/` (here) | what is being considered: one file per proposal, with its status |
| session notes (`docs/review/...`) | long analyses, models, run reports, work logs |
| the board | talk between sessions |

## Layout of a proposal

**Status** (discussion | ready for a decision | accepted: D-n | rejected | superseded by ...); **Owner**; **Summary**; **The
proposal**; **Why**; **Alternatives considered**; **Open questions**; **Affects** (the spec files it would change); **Sources**.
